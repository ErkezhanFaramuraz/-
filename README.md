Тапсырма 1:
Массив және Х санын алып, массивтің элементтерінен қосындысы Х болатын сандарды табу.  
Жұп табылса экранға шығару, табылмаса "Мұндай қосынды табылмады" деп жазу керек.

Бағдарламаны қалай жаздым:
- Алдымен дайын массив қойдым: {1, 2, 3, 4, 5, 6}
- Пайдаланушыдан Scanner арқылы Х санын енгіздім
- Барлық элементтерді екі for циклімен тексердім
- Егер қосындысы Х-қа тең болса, System.out.println арқылы шығарып отырдым
- Егер ештеңе табылмаса, "Мұндай қосынды табылмады" деген хабар шығарады.

  Қорытынды: Бұл тапсырмада мен массив элементтерінің қосындысын тексеруді үйрендім. Пайдаланушы енгізген X санына сәйкес келетін жұп элементтерді табу үшін екі for циклін қолдандым. Егер қосынды табылса, нәтижесін экранға шығарады, ал табылмаса — арнайы хабар көрсетіледі. Осылайша бағдарлама массивтегі барлық мүмкін комбинацияларды тексеріп шығады. Бұл жұмыс арқылы мен: Массивпен жұмыс жасауды, Циклдер арқылы элементтерді салыстыруды, Шарт операторын (if) қолдануды, Пайдаланушыдан дерек алуды (Scanner) меңгердім.

Тапсырма 2:
Методтар жазу:
	•	2 int қабылдайды және қосындысын қайтарады
	•	3 int қабылдайды және қосындысын қайтарады
	•	4 int қабылдайды және қосындысын қайтарады

Бағдарламаны қалай жаздым:
	•	Бірдей атпен бірнеше метод жаздым (sum), бірақ параметрлер саны әртүрлі
	•	2 параметрлі метод екі санды қосады
	•	3 параметрлі метод үш санды қосады
	•	4 параметрлі метод төрт санды қосады
	•	Нәтижені return арқылы қайтарамын
	•	main ішінде Scanner көмегімен қолданушыдан сандар енгізіп алдым
	•	Қосындыны экранға шығарып отырдым

	Қорытынды: Бағдарламада цикл (while) мен арифметикалық амалдар (% және /) қолданылды. Жұмыс барысында: Scanner арқылы қолданушыдан сан енгізуді, % 10 көмегімен соңғы цифраны бөлуді,	/ 10 арқылы санды қысқартуды, Әр цифрды қосындыға қосуды меңгердім. Нәтижесінде кез келген бүтін сан үшін оның цифрларының қосындысын шығаратын қарапайым әрі тиімді бағдарлама жазылды. Бұл тапсырма арифметикалық амалдарды және циклді тәжірибеде қолдануға үйретті.
